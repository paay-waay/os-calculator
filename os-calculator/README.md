# October Six Calculator

Static, self-contained GitHub Pages site for the October Six Design Fee & Project Investment Estimator.

## Deploy with GitHub Pages

1. Create the GitHub repository `os-calculator`.
2. Upload the contents of this folder to the repository root.
3. Commit to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.

The published address will normally be:

`https://paay-waay.github.io/os-calculator/`

No build command, package manager, or dependency installation is required.

## Included O/S icon assets

- Browser favicons in 16, 32, 48 and 64 px sizes
- Apple Touch icons for 120, 152, 167 and 180 px
- PWA icons in 192 and 512 px
- 1024 px master artwork
- Complete native iOS `AppIcon.appiconset` with `Contents.json` for Xcode
- `site.webmanifest` and iOS Home Screen metadata already connected in `index.html`

For GitHub Pages, upload the complete folder contents. The icon will be used when the calculator is added to an iPhone or iPad Home Screen.
